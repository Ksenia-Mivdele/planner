# Планировщик

Локальный веб-планировщик личных и рабочих задач.

## Запуск

В папке `app` выполните:

```powershell
pnpm install
pnpm dev
```

Затем откройте `http://127.0.0.1:5173`.

## Проверки

```powershell
pnpm lint
pnpm format:check
pnpm test
pnpm build
```

Данные сохраняются локально в IndexedDB браузера. В разделе «Настройки» доступен экспорт и импорт JSON-резервной копии.
