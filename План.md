# План: разработка «Планировщика»

Этот файл содержит порядок работ и проверок. Требования продукта находятся в [ТЗ.md](ТЗ.md).

## Выполнено

### Этап 1. Основа приложения

- React, TypeScript, Vite и локальная IndexedDB;
- маршруты недели, списка, настройки и параметров;
- проверка: сборка и запуск приложения.

### Этап 2. Расписание и свободное время

- настройка рабочего, личного и недоступного времени по дням;
- расчёт свободного времени без двойного учёта пересечений;
- проверка: модульные тесты расчётов и ручная настройка каждого типа интервала.

### Этап 3. Календарь и записи

- недельная сетка, создание, редактирование, удаление;
- типы «Задача», «Встреча», «Событие», цвета категорий, статусы;
- изменение длительности и отмена последнего изменения;
- проверка: создать по одной записи каждого типа, перенести и изменить длительность.

### Этап 4. Обзор и надёжность

- список, поиск и фильтры;
- темы, экспорт, импорт с проверкой, очистка;
- проверка: экспортировать данные, импортировать их в пустую базу, проверить неверный JSON и очистку.

### Этап 5. Доработка по сверке ТЗ

- еженедельные повторения с горизонтом четыре недели;
- зоны недоступности, сворачивание часов, конфликты, просрочка и перенос на сегодня;
- период в списке, длительность, зачёркивание завершённых и переход к нужной неделе;
- значки типов в карточках.

## Проверки перед публикацией

1. Выполнить `pnpm lint`, `pnpm format:check`, `pnpm test`, `pnpm build` в папке `app`.
2. Открыть опубликованную версию и пройти первый запуск.
3. Создать обычную и повторяющуюся записи, проверить значки, конфликт, завершение и скрытие.
4. Проверить расчёт свободного времени при недоступном периоде и пересечении.
5. Проверить экспорт и импорт в браузере.

## Следующее улучшение после MVP

Добавить сквозные Playwright-тесты для повторений, изменения длительности, импорта, скрытия завершённых и перехода из списка. Совместная работа и синхронизация остаются за границами первой версии.
